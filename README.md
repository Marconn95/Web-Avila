# Web de Descarga de Reportes PDF por Número de Cédula

Este proyecto es una aplicación web simple hecha con **Flask** que permite a los usuarios ingresar un número de cédula y descargar un archivo PDF previamente generado.  
Los archivos PDF deben estar guardados en una carpeta específica con el nombre del archivo igual al número de cédula.

## 🚀 Características
- Interfaz web sencilla para ingresar el número de cédula.
- Descarga directa de PDFs almacenados en el servidor.
- Uso de Flask y HTML básico.
- Acceso libre (no requiere autenticación).
